
# Code signing policy

Free code signing provided by SignPath.io,
certificate by SignPath Foundation.

## Signing responsibilities

- Authors and reviewers: Project maintainers.
- Approvers: Project maintainers.

## Privacy

This program will not transfer any information to other
networked systems unless specifically requested by the user
or the person installing or operating it.

## Signed artifacts

Official Windows executable releases published in GitHub Releases.
